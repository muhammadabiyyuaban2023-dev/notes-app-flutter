## Tentang Aplikasi
Notes App adalah aplikasi pencatatan sederhana berbasis Flutter yang digunakan untuk membuat, melihat, mengubah, dan menghapus catatan.

Aplikasi ini dibuat untuk membantu pengguna mengelola catatan dengan mudah melalui tampilan yang sederhana.

## Teknologi yang Digunakan
- Flutter
- Dart
- Provider (State Management)

## Fitur Aplikasi
- Menampilkan daftar catatan
- Menambahkan catatan
- Mengubah catatan
- Menghapus catatan

## Struktur Pengembangan
Aplikasi menggunakan Provider dengan ChangeNotifier untuk mengelola perubahan data dan memperbarui tampilan aplikasi.

## Cara Menjalankan
1. Clone repository.
2. Jalankan `flutter pub get`.
3. Jalankan `flutter run`.
